# 검증 기록

검증일: 2026.09.29

## 이번 갱신

- 졸업예정: 본인이 제공한 2027년 2월을 웹·인쇄용 HTML의 공유 프로필에 반영했습니다.
- 콘텐츠/공개 경계/이력서/배포 경로 Node 테스트 25개를 로컬에서 실행해 통과했습니다.
- 경량 정적 빌드로 8개 HTML을 생성했습니다.
- 저장소명을 바꿔도 CI 사이트 경로가 실제 `GITHUB_REPOSITORY`를 따르게 했습니다.
- 브라우저 검증을 `scripts/browser-check.mjs`에 추가했습니다. 홈 6개 폭, 사례 5개×2개 폭, 실제 페이지 이동, 이력서와 PDF 바이트, 404를 검사합니다.
- GitHub Actions가 정식 Astro 컴파일, PDF/공유 이미지 생성, 브라우저 검증, Pages 배포를 각각 실행하도록 구성했습니다.

## 정식 빌드 증거

```sh
npm test
npm run release
```

최종 정식 Astro 빌드 결과는 해당 커밋의 GitHub Actions build job 및 `portfolio-verified` artifact를 기준으로 확인하세요. 스크립트를 추가한 것 자체는 실행 성공의 증거가 아닙니다.

초기 제작과 이번 수정의 로컬 환경은 npm registry 접근이 제한되어 있습니다. 로컬 경량 빌드 결과를 Astro 컴파일 성공으로 표시하지 않습니다. CI가 성공해야 의존성 설치와 Astro 경로까지 검증된 것입니다. CI build 성공, 생성 파일 저장, Pages deploy 성공은 각기 별도 상태입니다.

## 기존 디자인 검토 범위

초기 전달본에서 홈 320~1440px, 상세 페이지 360/1440px, 2페이지 PDF의 시각적 검토를 수행했습니다. 실제 화면이 아닌 개념도를 사용하며 실무 저장소 URL은 노출하지 않습니다. 새로운 PDF는 졸업 월 반영 후 다시 생성·시각 확인합니다.

## 유지보수 주의

- `public/resume.pdf`는 재생성 명령 또는 CI에서 갱신합니다.
- 한국어 인쇄 글꼴이 다른 OS에서는 줄바꿈이 달라질 수 있습니다.
- 공개 가능한 추가 성과 지표와 구체적인 현업 협업 일화는 확인된 내용만 추가합니다.
- 폰트 파일, 비공개 원본 코드, 실제 운영 식별정보를 artifact에 추가하지 않습니다.
